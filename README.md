# FedCBD: A Collective Behaviors Dynamics Approach for Personalized Federated Learning, submitted to NIPS 2025

## Suggested environment
* CUDA 12.1
* Python 3.11
* Pytorch 2.1.0
* Torchaudia 2.1.0
* Torchvision 0.16.0
* Torchtext 0.16.0
* Numpy 1.26.0

## Quick run
```
run.py
```
### The description of main files
1. FedCBD.py: FedCBD class files, including the implementation process of algorithms;
2. config.py: algorithm configuration file;
